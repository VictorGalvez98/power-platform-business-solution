# Plugins

This directory documents Dataverse plugins used by the solution.

## Purpose

Plugins will be introduced when server-side business logic is required and cannot be appropriately handled through configuration or other platform capabilities.

## Potential Uses

Examples include:

- Server-side validation
- Complex business rules
- Data manipulation
- Transaction-aware operations
- Extending Dataverse behavior

## Development

Plugin source code will be located under:

`/src/plugins/`

Tests will be located under:

`/tests/plugins/`
