# Custom Connectors

This directory documents Custom Connectors used to integrate Power Platform with external services.

## Purpose

Custom Connectors may be introduced when the solution needs to communicate with external APIs that are not adequately supported by existing connectors.

## Potential Capabilities

- REST APIs
- External business services
- Authentication
- Custom operations
- Data retrieval
- Data submission

## Security

Authentication and secrets must never be committed to source control.

Environment-specific configuration should be handled through appropriate ALM mechanisms.

## Current Status

No Custom Connectors implemented yet.
