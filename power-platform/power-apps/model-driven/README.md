# Model-Driven Apps

This directory contains documentation related to Model-driven Apps.

## Purpose

Model-driven Apps will be used where the application's data model and Dataverse capabilities provide the appropriate user experience.

Potential capabilities include:

- Forms
- Views
- Dashboards
- Business rules
- Business process flows
- Command customization
- JavaScript
- Security-driven experiences
