# Screenshots

This directory contains screenshots and visual evidence of the solution during its development.

## Purpose

Screenshots can demonstrate:

- Application interfaces
- Model-driven Apps
- Canvas Apps
- Dataverse configuration
- Power Automate flows
- Power Platform solutions
- Deployment processes
- User experiences

## Guidelines

Screenshots should provide useful evidence of the implementation.

Avoid including:

- Personal information
- Credentials
- Secrets
- API keys
- Sensitive business data

Screenshots should be updated as the application evolves.
