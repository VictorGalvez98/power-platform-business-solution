# JavaScript

This directory contains JavaScript used to extend Power Apps and model-driven applications.

## Potential Uses

JavaScript may be used for:

- Form events
- Field behavior
- Client-side validation
- User interface customization
- Web API interactions

## Principles

JavaScript should only be used when configuration or native platform capabilities are not sufficient.

Business-critical validation should not rely exclusively on client-side JavaScript.
